What's happening

Banner takes a flat Message[] ({{ '{type, text}' }}) and renders one block per message with an icon for its type — no Material dependency, so it works the same whether or not the app is Material-themed. Panel (on mat-expansion-panel) and Card (on mat-card) share the same header rules: an optional icon and required header on one line, an optional subheader on the next, both always visible; their content is projected in by the caller. Panel's content only shows once expanded; Card's is always visible. Nothing here calls an API — everything is hardcoded.
