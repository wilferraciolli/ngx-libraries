About Dynamic Forms

The DynamicForm component provides a configuration-driven approach to building forms:

  • Schema-based: Define form structure with an array of field definitions
  • Type-safe: Full TypeScript support with generics extending BaseSchema
  • Flexible: Supports text, password, search, date, time, datetime-local, radio, select, checkbox, number, and range fields
  • Validation: Built-in required/minLength/maxLength rules with inline error display
  • Signals-based: Built on Angular's experimental Signals Forms API (@angular/forms/signals)

This approach reduces boilerplate and makes forms more maintainable and testable.
