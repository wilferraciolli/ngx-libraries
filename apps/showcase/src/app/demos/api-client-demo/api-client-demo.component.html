About ApiClientService

The ApiClientService provides a Promise-based wrapper around Angular's HttpClient, built around the Wiltech API's HAL-ish envelope shape: {{ '{ _data: { [rootKey]: resource } }' }}.

  • Envelope unwrapping: get/post/put take a rootKey and return the unwrapped resource directly (not the raw envelope)
  • Promise-based: methods are async — no manual .subscribe() needed
  • HATEOAS-style links: resolve() / requireLink() turn a resource's action link into a callable URL
  • Signals resources: resource() / collectionResource() wrap httpResource for reactive, reloadable reads
