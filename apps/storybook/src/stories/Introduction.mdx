# ngx-libraries

A catalogue of every `@wiltech-labs/ngx-*` Angular package, rendered straight from the library
source in this repo. Each sidebar group is one package; each story under it is one use case.

## How to read a story

- **Canvas** shows the component on its own. **Docs** shows every use case on one page, with a
  description and an inputs/outputs table generated from the source by Compodoc.
- **Controls** (bottom panel) change the component's inputs live.
- **Actions** list every output a component emitted, with its payload.
- **Accessibility** runs axe checks on the current story.

## Toolbar

- **Theme**: light, dark or system. Every colour comes from the Material 3 `--mat-sys-*` tokens,
  so the whole catalogue follows it.
- **Locale**: English (UK) or Greek. Translations, relative dates, form date/time fields and the
  calendar all switch live.

Each package's own `README.md` in `packages/<name>/` is the full reference.
